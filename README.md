# Cricbuzz Recent Matches Scraper (Playwright Python)

A Python automation script using Playwright to scrape live and recent match scores, team names, and match details from Cricbuzz, and capture a full-page verification screenshot.

---

## Features

- **Automated Browser Navigation**: Launches Chromium in headed mode and navigates to Cricbuzz's recent matches page.
- **Data Extraction**: Uses XPath and CSS class locators to identify specific teams (India, Sri Lanka), their current scores, and final match status details.
- **Visual Verification**: Captures and saves an automated page screenshot upon completion.

---

## Tech Stack

- **Language**: Python 3.x
- **Automation Tool**: Playwright (Synchronous API)
- **Browser Engine**: Chromium
